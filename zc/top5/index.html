제일 쉬운 설치법 (5개 공통)
클로드 코드를 열고, 아래 각 스킬의 「이 문장 그대로 붙여넣기」를 복사해 보내세요. 클로드가 알아서 설치합니다. 잘 안 되면 그 아래 「직접 치는 명령」을 클로드 코드 입력창에 한 줄씩 치면 됩니다.
클로드 코드에서만 됩니다. 일반 클로드 채팅(claude.ai 대화창)에는 스킬이 안 깔립니다. 데스크톱 앱의 Code 탭이나 터미널의 클로드 코드를 쓰세요.

1와치 (watch) — 클로드가 영상을 직접 본다

만든 곳 bradautomates · 무료 공개

유튜브·릴스·틱톡 링크나 내 컴퓨터 영상 파일을 주면, 클로드가 장면을 캡처해서 보고 대사까지 받아 적은 다음 질문에 답합니다. 잘 터진 릴스 구조를 뜯어볼 때 씁니다.

이 문장 그대로 붙여넣기
이 스킬 설치해줘: https://github.com/bradautomates/claude-video
직접 치는 명령 (한 줄씩)
/plugin marketplace add bradautomates/claude-video
/plugin install watch@claude-video
이렇게 쓰세요
/watch [릴스 주소] 이 릴스 장면 순서랑 대사 정리해주고, 왜 잘 됐는지 알려줘
자막이 없는 영상은 받아 적기에 무료 음성 인식 키(Groq)가 필요합니다. 처음 쓸 때 클로드가 물어보면 안내대로 하면 됩니다. 키가 없어도 장면 보기는 됩니다.
공식 페이지 → github.com/bradautomates/claude-video

2클로드 멤 (claude-mem) — 창 닫아도 기억한다

만든 곳 thedotmack · 무료 공개

클로드 코드는 새 창을 열면 어제 한 일을 모릅니다. 이걸 깔면 한 일을 알아서 기록해 두고, 다음 창을 열 때 그 기억을 꺼내 줍니다. 같은 설명을 매번 다시 안 해도 됩니다.

이 문장 그대로 붙여넣기
이 스킬 설치해줘: https://github.com/thedotmack/claude-mem
직접 치는 명령 (한 줄씩)
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem

설치하고 클로드 코드를 껐다 켜면 끝입니다. 그다음부터는 따로 시킬 게 없습니다.

설치 중 체험판·결제 수단을 물어보면 꼭 안 해도 됩니다. 기억 방식 고르는 화면에서 내 Anthropic 요금제(Anthropic plan)를 고르면 추가 결제 없이 씁니다.
공식 페이지 → github.com/thedotmack/claude-mem
